# Sharpa 灵巧手适配分支

本分支保存 Apex 真机数采、Raw → HDF5 → LeRobot 转换及 replay 的 Sharpa 灵巧手适配版本，基于初始导入 PR #1 的代码建立。

- 数据采用统一 78 维布局，左右灵巧手各 22 个关节；夹爪槽位 54、77 在此模式下屏蔽。
- 包含仓库已有的同步录制契约、转换代码、离线 replay 校验、模拟及相关配置与文档。
- 统一 replay 的真实硬件执行入口尚未实现；模拟通过不代表真机回放已验收。
- 外部链接的 integrations/manus_sharpa 模块、机器人端独立部署脚本和第三方 SDK 尚未完整纳入；本分支不是完整部署包。

后续夹爪适配应使用独立分支及明确的末端类型配置，避免混淆两种数据契约。
